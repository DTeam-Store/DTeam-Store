## 👋 Qui sommes-nous ?

**DTeam Store** est une équipe de développeurs passionnés qui conçoit et vend des produits numériques pour les créateurs de communautés :

- 🤖 **Bots Discord** développés en Python, entièrement configurables
- ⛏️ **Plugins Minecraft Java** compatibles Spigot et Paper

Notre objectif : proposer des outils fiables, bien documentés et adaptables à chaque serveur, avec un vrai suivi après l'achat.

## 🎯 Notre approche

| | |
|---|---|
| ⚙️ **Configurable** | Chaque produit s'adapte à votre communauté, sans toucher au code. |
| 📚 **Documenté** | Une documentation complète accompagne chaque produit. |
| 🛟 **Support inclus** | Une aide réactive via notre serveur Discord. |
